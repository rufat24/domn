# Домино 101 — Academy

Игра в домино «101» 2×2 (партнёры сидят по диагонали) с сильным ИИ, тренажёрами счёта камней и учебником стратегий. Без зависимостей: чистый JavaScript (ES-модули), без сборки.

## Запуск

> Открывать `index.html` двойным кликом (`file://`) **нельзя** — браузер блокирует модули и Web Worker. Используйте сервер:

```bash
npm start
```

Откройте http://localhost:8080/. Тесты: `npm test`. Бенчмарк ИИ: `npm run bench`.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → ветка с кодом, папка **/ (root)** → Save. Адрес: `https://<user>.github.io/domn/`. Все пути относительные, `.nojekyll` уже в корне.

## Что внутри

- **Играть** — матч до 101, четыре уровня ИИ, трекер камней, прогноз «рыба или выход», разбор ходов и подсказки.
- **Тренировка** — 6 генерируемых упражнений с точными (не «на глаз») ответами + тест по игре в паре.
- **Гид** — учебник: счёт камней, чтение пасов, концовка и теорема о рыбе, игра в паре, ошибки.
- **Настройки** — правила (по умолчанию: цель 101, открывает 1-1, 0-0 = 25, 6-6 = 12; сверьте с вашими!).

## Об ИИ честно

Уровни «лёгкий/обычный» — эвристики; «сильный» и «эксперт» — выборка скрытых рук по информации из пасов (PIMC) + точный перебор концовки. Эксперт выигрывает у «обычного» лишь около 57% раздач (+8,8 очка на раздачу): домино — игра с большой долей случая. Прогноз «рыба/выход» откалиброван на играх самих ИИ, а не людей.

Только честные сигналы: ходы и пасы. Условные знаки партнёру не обучаются и не поддерживаются.
